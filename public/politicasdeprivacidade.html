1. Quem somos

Esta política se aplica ao "Painel de Publicação — Grupo CVL", uma ferramenta interna desenvolvida e operada pelo Grupo CVL Soluções Tecnológicas para automatizar a publicação de vídeos e conteúdos em plataformas de terceiros (YouTube, Instagram e Facebook) em nome de seus próprios usuários e/ou clientes autorizados.

2. Quais dados o aplicativo acessa e por quê

Para funcionar, o aplicativo solicita autorização (via OAuth) para acessar as seguintes contas e escopos, exclusivamente para realizar publicações solicitadas pelo próprio usuário:

  • YouTube (Google/YouTube Data API v3, escopo youtube.upload): permissão para enviar vídeos, título, descrição e tags ao canal do YouTube conectado pelo usuário.
  • Instagram e Facebook (Graph API): permissão para publicar vídeos e legendas nas páginas/contas conectadas pelo usuário.

O aplicativo não acessa, lê ou coleta nenhum outro dado das contas conectadas além do estritamente necessário para publicar o conteúdo enviado pelo próprio usuário através do painel.

3. Armazenamento dos dados

Os vídeos enviados são armazenados temporariamente em um repositório privado no GitHub, usado apenas como intermediário técnico para disponibilizar o arquivo às APIs do Instagram e Facebook, podendo ser apagados manualmente pelo usuário logo após a publicação.

Credenciais de acesso (tokens) inseridas no painel ficam salvas apenas no armazenamento local do navegador do próprio usuário (localStorage), e não são enviadas a nenhum servidor além das próprias plataformas (Google, Meta e GitHub) para realizar as publicações.

4. Compartilhamento de dados

Não vendemos, alugamos ou compartilhamos dados de nenhuma conta conectada com terceiros. Os dados trafegam apenas entre o navegador do usuário e as APIs oficiais do Google, Meta e GitHub, exclusivamente para executar a publicação solicitada.

5. Revogação de acesso

O usuário pode revogar a qualquer momento o acesso concedido a este aplicativo diretamente nas configurações de segurança da sua Conta Google (myaccount.google.com/permissions) ou do Meta Business Suite, conforme a plataforma conectada.
